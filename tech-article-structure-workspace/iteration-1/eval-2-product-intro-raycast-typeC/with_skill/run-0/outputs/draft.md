## はじめに

みんな Raycast を使っている。Spotlight を置き換えて、アプリ起動もクリップボード履歴もスニペットも、キーボードから手を離さず一瞬で呼べる。便利だ。

でも自分には、一つだけ毎回手作業で詰まる操作があった。`<ここに具体的な操作を書く：例「特定フォーマットの ID を生成してコピーする」>`。Raycast を開く → 別のアプリ/サイトに切り替える → コピーして戻る、という地味な2〜3手を、1日に何度も繰り返していた。一回数秒でも、回数が積もると「また切り替えるのか」というストレスになる。

週末にこの操作を Raycast 拡張にしてみた。結果、コマンドバーにキーワードを打つだけで一発で終わるようになった。この記事では、その拡張で何ができるか・どうインストールして使うか・そして「自分も作ってみたい」人向けの最小メモまでをまとめる。読み終えたら、まずインストールして試せる状態にすることがゴールだ。

## 自分で作りたい人向けの最小メモ

Raycast 拡張は思っていたより気軽に作れる。雛形はコマンド一発で出る。

```bash
npm init raycast-extension
```

生成されたテンプレに、`<使った主要 API：例「@raycast/api の `Clipboard` と `List` コンポーネント」>` を足しただけで動くものになった。UI は React で書くので、普段フロントを触っている人ならとっつきやすいはずだ。
