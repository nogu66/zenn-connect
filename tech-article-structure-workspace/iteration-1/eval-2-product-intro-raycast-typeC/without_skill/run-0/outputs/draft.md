## こんな課題、ありませんか？

私はある作業を、1日に何十回も繰り返していました。

- クリップボードにコピーした文字列を、別のフォーマットに整形して貼り直す
- そのたびにエディタを開いて、手で直して、またコピーして……

ひとつひとつは数秒の作業です。でも1日に何十回もやると、地味に集中力を削られます。「この数秒、人間がやる必要ある？」と思った瞬間が、この拡張を作るきっかけでした。

Raycast を使っているなら、こういう「ちょっとした繰り返し作業」を Raycast の中で完結させたくなりますよね。**この拡張は、その繰り返しをキーストローク数回で終わらせます。**

## 何ができるのか

まずは動いているところを見てください。

![拡張のデモ GIF](/images/raycast-extension/demo.gif)
*（デモ GIF をここに配置。コマンドを呼び出して結果が返るまでの一連の流れを見せる）*

主な機能は次の3つです。

- **ワンアクション変換**: クリップボードの内容を、決めたフォーマットに即変換
- **複数フォーマット対応**: よく使う変換パターンをあらかじめ登録しておける
- **履歴から再利用**: 直近の変換結果をその場で呼び出せる

## インストール方法

### 前提条件

- macOS（Raycast の動作環境）
- Raycast v1.x 以降がインストール済み

### Raycast Store から入れる（おすすめ）

1. 上のリンク、または Raycast 内で `Store` を開く
2. 拡張名「〇〇」を検索
3. `Install` を押す

これだけで使えるようになります。追加の API キーやログインは不要です。

:::details ソースからビルドしたい人向け
開発版を試したい場合は、リポジトリをクローンして以下を実行します。

```bash
git clone https://github.com/your-name/your-extension.git

```

`npm run dev` を実行すると、Raycast に開発中の拡張が自動で読み込まれます。
:::

## 使い方（まずこれだけ）

最短で効果を体感する手順です。

1. Raycast を開く（デフォルトは `⌘ + Space`）
2. コマンド名「〇〇」を入力して Enter
3. 変換したいテキストはクリップボードから自動で読み込まれます
4. 結果が表示されたら `⌘ + C` でコピー、または `Enter` で貼り付け

## 実装の裏側（軽く）

週末プロジェクトなので大したことはしていませんが、ひとつだけ。

Raycast の拡張は TypeScript + React で書きます。クリップボードの読み書きは公式の `@raycast/api` がそのまま使えるので、コア処理は驚くほど短く済みました。

```typescript
import { Clipboard, showHUD } from "@raycast/api";

export default async function Command() {
  const text = await Clipboard.readText();
  if (!text) {
    await showHUD("クリップボードが空です");
    return;
  }
  const converted = convert(text);
  await Clipboard.copy(converted);
  await showHUD("変換してコピーしました");
}
```

UI を作り込まなくても `showHUD` で十分フィードバックが返せるのが、Raycast 拡張の気持ちいいところです。

## 既知の制約と今後の予定

正直に書いておきます。

- いまは単一フォーマットの変換が中心で、複数ステップの変換チェーンには未対応
- 大きすぎるテキスト（数 MB 級）は想定していません

今後やりたいこと。

- カスタム変換ルールをユーザーが定義できるようにする
- 変換履歴の検索

「こういう変換が欲しい」という要望があれば、ぜひ教えてください。
