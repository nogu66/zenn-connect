## 4. タイトル候補（3つ）

> 違うトーンで3つ出す。書き終わってから1つ選ぶ。

1. **強硬:** 「[断定的・煽り気味のタイトル]」
2. **中庸:** 「[自然なトーンのタイトル]」
3. **謙虚:** 「[控えめだが具体的なタイトル]」

**例（テーマ: File Systemの活用）:**
1. 強硬: 「ContextをSystemプロンプトに詰めるのはもう終わりだ」
2. 中庸: 「AgentにFile Systemを持たせると何が変わるか」
3. 謙虚: 「Agent運用1ヶ月でわかった、状態管理にFile Systemを使う理由」
